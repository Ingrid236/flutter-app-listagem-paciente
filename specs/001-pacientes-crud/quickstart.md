# Quickstart: Pacientes CRUD

## Requisitos de Ambiente

- Flutter SDK (versão 3.x recomendada).
- Dart (>= 3.0.0).

## Instalação e Execução

1. Certifique-se de estar na raiz do repositório/projeto flutter:
   ```bash
   cd c:\mobile\flutter-app-listagem\listagem
   ```
2. Baixe e alinhe as dependências exigidas para o BLoC e Equatable:
   ```bash
   flutter pub add flutter_bloc equatable intl
   ```
3. Execute o aplicativo em seu emulador preferido (iOS/Android):
   ```bash
   flutter run
   ```

## Testes

Os testes são parte fundamental deste modelo (TDD é obrigatório pela constituição). Para rodar todas as suítes:
```bash
flutter test
```
Para forçar uma visualização estrita de formatação da constituição:
```bash
flutter analyze
flutter format .
```
